# Lovely Aaron Essentials

Proyecto de tienda virtual de belleza desarrollado con Node.js y Express.

## Tecnologías

- Node.js
- Express
- HTML/CSS
- JavaScript

## Ejecutar proyecto

npm install
npm run dev

## Endpoints

GET /api/productos
GET /api/pedidos
POST /api/pagos-pse
GET /api/pagos-pse/:ref
